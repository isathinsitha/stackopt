# StackOpt case intake

Start with a marked-up drawing or dimensioned assembly section and one decision. A redacted excerpt is enough if it retains the inputs needed to check the stack. Native CAD is useful for testing extraction.

| Field | Fill in |
| --- | --- |
| Assembly and source | Assembly or alias, drawing number or alias, revision, configuration, and view or section. Attach the relevant excerpt with its units. Identify the person who can confirm the requirements. |
| Drawing decision | Identify the callout and its current limits. List each permitted tighter, looser, or shifted tolerance using actual lower and upper limits, or signed deviations from the nominal. Include process or cost evidence only if it should affect the choice. |
| Functional requirement | Describe what must fit, move, or remain separated, and at what location and operating condition. Give the approved minimum and/or maximum, units, and source. Identify every other approved requirement that uses the adjustable callout. |
| Stack dimensions | Mark the path on the section or write its signed equation, such as `clearance = +bore diameter − shaft diameter`. For each term give the part and occurrence, drawing callout and revision, nominal, lower and upper deviation, and units. State when terms reuse the same physical dimension. |
| Operating conditions | Give the drawing reference temperature and operating range. Where relevant, give each part's material, expansion coefficient and source, and any differences in part temperature. Describe any alignment, form, deflection, or assembly constraint that could change the functional limit. State which effects the requirement already allows for. |
| CAD and review | If available, identify the CAD application, version and intended assembly configuration. Indicate which inputs and results can be published. Identify who can review the conclusion if the choice depends on engineering judgment. |

If a field is unknown, record it as unknown. Keep private files and filled-in intake forms with private case evidence.
